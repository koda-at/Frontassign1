# Assignment 1: HTML & CSS Basics

Name: Kairov Adilbek
Group: IT-2501

## Objective
Create a personal webpage using HTML and CSS and publish it with GitHub Pages.

## Part 1: Introduction to HTML

### Steps 0–1: Page Structure and Text
I created index.html with the basic HTML structure and the title “My First Webpage”. I added headings and a paragraph about myself.

### Step 2: Lists
I created an ordered list of my hobbies and an unordered list of my favorite websites.

### Step 3: Images and Links
I added my photo and clickable links to Instagram and Yandex Music.

### Step 4: Button
I added a “Click Me” button with no extra functionality.

## Part 2: Intermediate HTML

### Step 5: Schedule Table
I created a class schedule with Subject, Day, and Time columns.

### Step 6: Two-Column Layout
I created a table with a menu column on the left and a main-content column on the right.

### Step 7: Emojis
I wrote a paragraph about my mood with three emojis.

### Step 8: Form
I created a form with name, email, and favorite-color inputs and a Submit button.

## Part 3: Introduction to CSS

### Steps 9–10: Styling and Inline CSS
I added CSS styling and used an inline style to make my mood paragraph blue.

### Step 11: Internal CSS
I used a style section inside head to change the background, heading font, and table borders.

### Step 12: External CSS
I moved the CSS rules into style.css and connected it to index.html with a link element.

### Steps 13–14: Selectors, Classes, and IDs
I used element, class, and ID selectors. I applied the highlight class to multiple elements and the main-heading ID to my main heading.

## Part 4: Intermediate CSS

### Step 15: Favicon
I added a PNG favicon for the browser tab.

### Step 16: Divs
I grouped my page into header, main-content, and footer containers and styled their backgrounds and padding.

### Step 17: Box Model
I added borders, margins, and padding and changed their values to compare the spacing.

### Step 18: Positioning
I created examples of static, relative, and absolute positioning.

### Step 19: Sizing
I used px, %, em, and rem units to size elements, including headings and my photo.

### Step 20: Float and Clear
I floated one box left and another right. I used clear: both to place a paragraph below them.

### Step 21: Publishing
I uploaded my project to a public GitHub repository and published it using GitHub Pages.

Website: https://koda-at.github.io/Frontassign1/
Repository: https://github.com/koda-at/Frontassign1

## Work Process
I built the HTML content first, then added CSS and checked the results in my browser. During publishing, I corrected the file location so index.html was directly in the repository’s main folder.

## Reflection
I learned how HTML structures a webpage and how CSS changes its appearance. I also learned that filenames and file locations must match the paths used in my code.
